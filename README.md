# 💥 SMS-BOMBER

**SMS-BOMBER** is an educational Python project designed to demonstrate how repeated HTTP requests and SMS request flows can be simulated in a controlled environment.

> ⚠️ **Educational Use Only** — This project must only be used in authorized testing environments. Do not use it to spam, harass, or disrupt other people or services.

---

## 🇬🇧 English

### ✨ Features

* 🐍 Python-based project
* 🌐 Demonstrates HTTP request workflows
* 🔄 Simulates repeated request operations
* 🧪 Designed for educational and testing purposes
* 📦 Includes a dependency/documentation setup file
* 🛑 Can be stopped manually during execution

---

## ⚙️ Installation & Usage

First, run the project documentation/dependency file to install the required Python libraries.

Then run:

```bash
python sms.py
```

The program will request a test phone number and demonstrate the request workflow in the configured testing environment.

> 🚨 Do not configure the project to repeatedly send SMS or verification codes to numbers you do not own or have explicit permission to test.

---

## 🧪 Recommended Testing

For safe testing, use:

* Your own test environment
* Mock HTTP endpoints
* Local servers
* Authorized API testing environments

This allows the request flow to be studied without sending unwanted messages to real users.

---

## 🛡️ Responsible Use

The author does not encourage:

* ❌ SMS spam

* ❌ Sending verification codes to other people's numbers
* ❌ Bypassing service rate limits

Use the project only for learning, development, and authorized security testing.
